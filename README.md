# Sonar Hub

Sonar Hub brings web apps and communication services into a single desktop workspace. This repository contains downloads and release notes.

- Windows x64 installer (`.exe`)
- macOS Apple Silicon disk image (`.dmg`)

Download packages and SHA-256 checksums from [Releases](https://github.com/tiriviri61/sonar-hub/releases). Check each release's signing and platform test status before installing.

Sonar Hub is a modified build based on [Ferdium](https://github.com/ferdium/ferdium-app). It changes the app identity and interface, service and tab handling, and background playback. Ferdium copyright and Apache 2.0 license notices are retained. Third-party component licenses are included in the distribution.
